# Data

The dataset is not included in the repository.

To reproduce the analysis:

1. Download the dataset from [https://www.kaggle.com/datasets/harshadapatil31/student-performance-and-study-habits-dataset].
2. Rename the file to `student_performance_dataset.csv`.
3. Place it in this directory.
4. Run `01_eda.ipynb`.

Expected file path:

```text
data/student_performance_dataset.csv
```

The dataset should contain 1,000 observations and the columns
used in the notebook.
